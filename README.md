## 💻 Tech Stack

**We don't talk about that anymore. 🤫**

Languages? Frameworks? Tools? I've used a bunch, and I'll probably use a bunch more.

With AI changing how we build software, I'm less interested in collecting programming languages like Pokémon cards.

What matters to me is understanding **how things work, why they work, what to build, and when to use (or avoid) a particular tool.**

The best tech stack? The one that solves the problem without creating five new ones.

*And yes, I still have my favorites. I'm just not starting a framework war today.*
